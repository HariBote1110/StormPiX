# 列辞書のフレーム配列ディスパッチ

## Decision

- 列辞書エンコーダのフレーム別 `if` / `elseif` 分岐を、短くなる場合だけ `d={...}` と `D(d[f+1])` の配列参照へ置換する。
- 外部フレーム番号を使う複数スクリプトでは、範囲外番号で描画しない既存契約を守るため、配列値の存在を確認してから `D` を呼ぶ。分岐形式の方が短い場合は従来形式を残す。

## Measurement

- `/Users/yuki/doc/al/pngX` の40フレームlosslessは 5,530文字から4,752文字へ778文字（14.1%）減った。画素往復は完全一致、スクリプト数は1のままである。

## Constraints / Gotchas

- `D` の引数名と配列のグローバル名はともに `d` だが、Luaの関数引数はローカルにshadowする。`onDraw` はグローバル配列を参照し、`D` 内は文字列引数を参照するため衝突しない。
