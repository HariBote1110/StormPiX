# 外部フレーム番号チャンネル

## 決定

- `ConvertOptions.frameChannel` に 1〜32 のコンポジット番号チャンネルを指定すると、生成 Lua は `f=0 function onTick()f=input.getNumber(N)end` を使う。未指定時は既存の tick カウンタをそのまま出力する。
- 分割された各スクリプトはローカルではなく全体のフレーム番号で分岐する。したがって同じチャンネルを全マイクロコントローラへ配線できる。
- 外部駆動時は各フレームが単独で描画可能な full 表現だけを選び、前フレームに依存する `keyframe-diff` は選ばない。

## 入力値の扱い

- 整数かつ当該スクリプトの担当範囲内なら、そのグローバルフレームを描画する。
- 範囲外、負数、小数はどの分岐にも一致しないため何も描画しない。未配線チャンネルの 0 は、範囲 `[0, 1)` を担当するスクリプトだけがフレーム 0 を描画する。
- `frameChannel` は整数 1〜32 以外では `RangeError` とする。

## 検証

- 実 Lua バイナリを用いる往復テストで、分割された生成スクリプトに 3, 0, 2, 1 の順で番号を与え、各フレームのピクセル一致を確認する。
- 同テストで負数、小数、全範囲外の入力は描画命令を出さないことを確認する。
