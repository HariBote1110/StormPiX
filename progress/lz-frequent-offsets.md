# 頻出距離の専用LZトークン

## 決定

- 通常参照の末尾6符号を頻出距離1・96・3072・288・595・2976へ割り当てる。
- これらの長い参照を5文字から3文字へ縮める。文字列の安全な文字集合は維持する。

## 計測

| 専用距離 | 成果物の文字数 | 判断 |
| --- | ---: | --- |
| なし | 7,945 | 基準 |
| 1・96・3072 | 7,754 | 採用 |
| 上記＋288 | 7,733 | 採用 |
| 上記＋595 | 7,717 | 採用 |
| 上記＋2976 | 7,714 | 採用 |

## 制約

- 専用距離の追加は通常参照の最大長を短くする。長距離参照の節約と通常参照の増加を成果物全体で比較する。
- 復号はロード時に行い、描画時の負荷は変わらない。
