# 2文字数値の共通復号

## 決定

- LZ距離・一致長と10 bitパレットの先頭2文字に同じBase64相当の数値復号関数を使う。
- ロード時のLZ復号ループを`repeat`にし、1回だけ書く描画呼び出しから別名を外す。

## 計測

| 試行 | astralの文字数 | 判断 |
| --- | ---: | --- |
| 変更前 | 6,954 | 基準 |
| 2文字復号を共通化 | 6,948 | 採用 |
| `repeat`ループ | 6,947 | 採用 |
| `drawRectF`の直接呼び出し | 6,943 | 採用 |

## 制約

- `repeat`の本体は必ず1回実行される。有効なフレーム列のLZデータは空にならない。
- Lua実行で全フレームの画素一致を確認し、生成コードはLua 5.3の構文だけを使う。
