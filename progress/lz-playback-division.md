# LZ再生器の除算と変数

## 決定

- tickを周回周期で剰余し、フレーム番号を整数除算で求める。
- Lua 5.3の整数除算`//`をpalette復号と画素座標にも使い、`math.floor`別名を除く。
- ロード時の復号と描画時の一時変数をグローバル代入にしてLua文字数を減らす。

## 計測

| 試行 | 成果物の文字数 | 判断 |
| --- | ---: | --- |
| DP・パレット再整列・一致候補64件まで | 7,146 | 基準 |
| tickの周回周期化 | 7,129 | 採用 |
| 整数除算と`math.floor`別名の削除 | 7,110 | 採用 |
| ストリーム位置の先行更新と復号変数短縮 | 7,091 | 採用 |
| 一般一致候補4件に戻す | 7,097 | 同じ候補品質で変換時間を短縮 |

## 制約

- `//`はStormworksが使うLua 5.3に存在する。色計算の値は非負なので、従来の`math.floor`と一致する。
- 復号はロード時に完了する。`onDraw`は従来と同じ各画素への矩形描画を行う。
