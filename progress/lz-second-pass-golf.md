# LZ復号器の追加短縮

## 決定

- 一般長距離参照と専用距離参照の長さ読み取りを一つにまとめる。
- `!`の参照では通常トークンの範囲外の値を一時的に使い、共通の長さ読み取りへ進める。

## 計測

| 試行 | 成果物の文字数 | 判断 |
| --- | ---: | --- |
| 入力由来の距離表 | 6,968 | 基準 |
| 長さ読み取りの共通化 | 6,964 | 採用 |
| `!`の識別値を共通条件へ入れる | 6,960 | 採用 |
| 水平run描画 | 7,050 | 描画器が82文字増えるため棄却 |
| `V`の文字列検索表 | 現行より長い | alphabetと表構築の文字数が増えるため棄却 |
| 安全な別順alphabetによる`V`の区間式 | 現行より5文字長い | 棄却 |
