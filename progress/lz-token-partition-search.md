# LZトークン配分探索

## 決定

- 通常トークン64通りを、リテラルrunの長さ1〜12と短距離一致の長さ3〜54へ配分する。
- 55以上の一致は5文字の長距離トークンを使う。

## 計測

- `astral_opening` は8,096文字から7,962文字へ、134文字減った。
- 近傍比較ではrun上限11と12が同率の最小値（7,962文字）だった。13は7,963、14は7,966、10は7,967、8は7,981、5は8,084文字だった。

## 検証

- 各候補でLua往復テストを通し、最終候補では実資産の30フレーム全pixelが一致することをCLIで検証する。
